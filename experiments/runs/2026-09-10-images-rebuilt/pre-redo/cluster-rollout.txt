The one rollout of this branch, and the proofs, 2026-09-10.

Order: make orchestrator-image (build + kind load, both nodes), then make step-3.
step-3 does not build the Python image and does not restart the orchestrator --
`make -n step-3` shows no docker build -- so the image was built and loaded
first and the securityContext change in the pod template is what rolled it.
