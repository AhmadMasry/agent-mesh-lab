Read-only, non-root proofs on orchestrator:dev, run on this host before any
cluster rollout. Every command below runs the container with --read-only and
--user 65532:65532, so the container starting at all is the first proof that the
image needs no writable root filesystem.

$ docker run --rm --read-only --user 65532:65532 orchestrator:dev id -u
65532
exit=0

$ docker run --rm --read-only --user 65532:65532 orchestrator:dev id
uid=65532(nonroot) gid=65532(nonroot) groups=65532(nonroot)
exit=0

$ docker run --rm --read-only --user 65532:65532 orchestrator:dev python -V
Python 3.14.7
exit=0

$ docker run --rm --read-only --user 65532:65532 orchestrator:dev uname -m
aarch64
exit=0

$ docker run --rm --read-only --user 65532:65532 orchestrator:dev sh -c touch /x

exit=1

exit=1
