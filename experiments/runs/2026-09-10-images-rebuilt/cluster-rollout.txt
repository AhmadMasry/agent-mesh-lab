The final rollout of this branch, and the proofs, 2026-09-10.

Order: make orchestrator-image (docker build --pull, then kind load onto both
nodes), then make step-3. step-3 does not build the Python image and does not
restart the orchestrator -- `make -n step-3` shows no docker build -- so the
image was built and loaded first and the pod-template change is what rolled it.
step-3 is required rather than optional here: the four Go binaries had to be
rebuilt by ko on the Debian 13 distroless base.
