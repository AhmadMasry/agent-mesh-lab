# The two step-2 Istio routes compared: object names, EVERY workload image, the four
# settings the lab sets, and the ztunnel container's env names. Rendered on this host.
# Taken 2026-09-12 after a review found that a name-only comparison had hidden an image
# difference (ztunnel 1.31.0 on the Helm route, 1.31.0-distroless on the istioctl route).
#
# Fallback route: istioctl manifest generate --set profile=ambient --set values.pilot.env.PILOT_ENABLE_AGENTGATEWAY=true -f deploy/step-2-ambient-agw/istio-meshconfig.yaml
# Helm route: helm template of base; istiod -f deploy/step-2-ambient-agw/istio-values.yaml;
#   cni --set profile=ambient; ztunnel -f deploy/step-2-ambient-agw/ztunnel-values.yaml
#   (which now carries profile: ambient) -- all at chart 1.31.0 from
#   https://blob.istio.io/istio-release/charts, exactly as make step-2 calls them.
# Images are read from each workload's containers and initContainers, parsed per
# document; `image:` text inside the injection-template ConfigMaps is not a workload
# image and is not compared.
