## What this measures
The three paths are gone from the application directory in the image. pytest is
still importable, and it is not coming from any of them: its origin is the
buildpack's own layer. paketo-buildpacks/python-package-managers-run runs plain
`uv sync` with no --no-dev (pkg/packagers/uv/uv_runner.go, args := []string{"sync"};
BP_UV_INSTALL_GROUPS only adds groups), and uv includes the dev dependency group
by default, which is where pytest==9.1.1 comes from in uv.lock. So the exclude
cannot remove it; only changing the lockfile's default groups could, and that
would take `uv run pytest -q` with it.
