WHAT DIFFERS FROM THE PLAN, OR NEEDS A WORD

    collection's 2 s pause; 46.0 s median from the send's start; driver stamps in steps.txt, counts.txt's last line) and exited 0: the Deployment exists with no pod, so
    kubectl logs deploy/extauthz waits for one and then fails, and the collection reports the fixture's ledger missing
    (ledgers-stderr.txt). The send itself was answered in 0 ms by the proxy's access line.
  - The load client on the Go path reads the agent card through the same ingress route, so under the unavailable authorizer
    its card GET is refused and no POST is sent (client line "resolve card: card request failed, status: 403 Forbidden").
    On the Python path the card GET crosses agw-central, where no policy is applied, and the POST is refused.
  - REST and gRPC rows used the load client only; no curl REST subscription was sent (D-2 sent one).
  - source_principal is empty on every decision line: the ingress accepts each request in plaintext from its own ztunnel,
    so the connection it holds has no peer certificate, which is C-7's reading for source.identity on the same hop.
  - The gRPC SendMessage checks read body_len 135 against size 133: the proxy forwards the protobuf frame as lossy UTF-8
    (ext_authz.rs l.442-455), and two bytes became three-byte replacement characters.
