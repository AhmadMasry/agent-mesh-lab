## #3212 [issue] state=closed state_reason=completed created=2026-08-27T19:42:48Z closed=2026-09-01T00:33:40Z
title: ext_proc never emits Frame::trailers, so gRPC grpc-status is dropped on every request
body: ## Summary  agentgateway's `ext_proc` filter never emits a trailers frame downstream, so **gRPC's `grpc-status` — which lives in trailers — is dropped on every request routed through an ext_proc-enabled route.** Clients see headers and a body but no status, and fail with `UNKNOWN: Stream removed`, while the gateway logs `http.status=200` with no error at all.  `Frame::trailers` appears zero times in `crates/agentgateway/src/http/ext_proc.rs`. Confirmed on **v1.0.0** and **v1.4.1**.
