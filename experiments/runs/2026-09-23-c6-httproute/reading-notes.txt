Experiment C, step C-6 -- reading notes. What each file in this directory is, what produced it, and what differs from
what was planned. Stamps UTC from date -u. The findings entry that cites this directory is "Experiment C / both
receivers / C-6, what a Gateway API HTTPRoute can separate". The cluster is the one C-5 rebuilt and proved
(experiments/runs/2026-09-23-c5-istio-policy-agw-central/), with C-5's policy removed and its clean check after.

THE WIRE (wire/)
  The load client's own requests, read on a raw TCP server on this host as B-3 read them (capture.py and run.sh are
  B-3's, run.sh's scratch path changed from b3 to c5): the binary built from git archive of 511fb145 (the same fixtures
  subtree d143d670 the cluster runs), three runs per mode, 18:05:03Z-18:05:04Z -- unary (MODE unset), subscribe
  (MODE=subscribe, TASK_ID naming no task) and stream (MODE=stream), each with CLIENT_RETRIES=0,
  CLIENT_SDK_RESEND=off, CLIENT_RETRY_ON=transport as the Job template renders them. runs/<mode>-<n>/ holds each run's
  two requests (the card GET and the POST) with every carriage return written <CR>, and its exit, stdout and stderr;
  the subscribe and stream runs exit 3 because the capture answers a JSON body, not an event stream -- the requests
  are what is read. runs/originals.txt gives each raw file's size and sha256 and the binary's hash; the raw bytes stay
  in a scratch directory. summarize.sh -> summary.csv: every POST is "POST / HTTP/1.1" with no query; SubscribeToTask
  and SendStreamingMessage carry "Accept: text/event-stream", SendMessage carries no Accept header; all three carry
  A2a-Version 1.0 and Content-Type application/json. The card GET carries no Accept and no A2A-Version.
