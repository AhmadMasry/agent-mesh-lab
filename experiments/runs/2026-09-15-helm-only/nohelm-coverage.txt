## 5. notes on the differences above (written by hand after the generated sections, 2026-09-15)
# Nothing here changes a verdict; each line says what a listed difference is.
#
# collector
#   - exporter `otlp` is `otlp_grpc` on the chart route: the chart's rewriteDeprecatedComponentNames
#     default renames it, and with that one rename applied the whole configuration is identical
#     (section 3). The component identity was recorded under versions.yaml key
#     opentelemetry-collector-chart on 2026-09-12 and is not re-read here.
#   - the ConfigMap key is `relay` rather than `collector.yaml`; the --config argument resolves to it
#     through the volume's items on each route (section 3, "config file").
#   - containerPort 13133 is declared by the manifest and not by the chart; both routes' probes
#     address 13133 by number, and a containerPort declaration opens no listener.
#   - the chart adds six downward-API variables (MY_POD_IP, OTEL_K8S_*); the rendered configuration
#     contains no `env:` reference (`grep -c 'env:'` over the chart ConfigMap's relay key -> 0).
#   - the chart adds a ServiceAccount with the pod's token mount off (section 4).
# Jaeger
#   - the chart probes /status on 13133 where the manifest probed / on 16686 (both the image's own
#     listeners); its Service publishes eleven ports beyond the manifest's three and its pod declares
#     nine beyond them; the three the lab addresses (4317, 4318, 16686) are present with the same
#     target ports.
#   - the chart adds a ServiceAccount with its token mount off (section 4).
# Prometheus
#   - global.scrape_timeout 10s is on the chart route only. The configuration reference
#     (https://prometheus.io/docs/prometheus/latest/configuration/configuration/, read 2026-09-15)
#     gives "[ scrape_timeout: <duration> | default = 10s ]", so the manifest's effective value is
#     the same. rule_files [] and four empty rule/alert keys are on the chart route only and name
#     no rule.
#   - args: the config path and the storage path differ with the mount paths (each resolves to the
#     same ConfigMap key, and storage is an emptyDir on both); --web.listen-address=0.0.0.0:9090 is
#     on the manifest only, and the command-line reference
#     (https://prometheus.io/docs/prometheus/latest/command-line/prometheus/, read 2026-09-15) gives
#     it the default 0.0.0.0:9090; chart-only are --storage.tsdb.retention.time=15d, the two console
#     paths, and --web.enable-lifecycle, which the same reference describes as "Enable shutdown and
#     reload via HTTP request." (default false). The lab sends no such request.
#   - the ClusterRole is wider on the chart route (section 3 lists the extra resources and the
#     /metrics nonResourceURL); every manifest rule is present. Recorded on 2026-09-12 as well.
# Hardening
#   - none of the three manifests declared a securityContext or a token setting, so the check "every
#     manifest hardening setting present on the chart route" holds trivially; what the chart route
#     declares is listed per Deployment in section 3 and is carried by the values files.
