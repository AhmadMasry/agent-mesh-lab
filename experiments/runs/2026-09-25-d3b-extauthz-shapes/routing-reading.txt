THE GO WORKER. Port 8080: a root ServeMux (/healthz, /control/inject, /control/reset, and / for everything else, behind the
ingress ledger), then the A2A ServeMux (the card; REST prefixes /message:send, /message:stream, /tasks, /tasks/,
/extendedAgentCard; / the JSON-RPC handler, a catch-all). Go 1.27.1's ServeMux cleans the escaped path and answers a
non-clean one (//, /./, /../) with a 307, dispatching nothing; it matches patterns segment by segment on each segment
unescaped, so %3A, %74, %73 decode and %2F never splits a segment; a GET pattern also takes HEAD. a2a-go's REST handler
dispatches SubscribeToTask on GET, HEAD and POST of /tasks/{idAndAction} when the unescaped segment ends in ":subscribe".
Its JSON-RPC handler takes POST only, reads the first JSON value with one json.Decoder (trailing data ignored), matches member
names without case, and ignores the content type. Port 8081: the same root mux, then grpc-go's ServeHTTP: POST, a
content type beginning "application/grpc", HTTP/2; the method is the decoded URL path's text after its last "/".

THE PYTHON ORCHESTRATOR. uvicorn (h11) decodes the path once, leniently (urllib.parse.unquote of the target before "?").
Starlette matches each route's pattern, which ends in "$", and Python's "$" also matches before one final newline: ^/$ matches
"/\n" and the subscribe route matches ".../t:subscribe\n". GET routes also take HEAD; a miss that a trailing slash would fix
gets a 307. The JSON-RPC route is Route("/", POST), content type ignored; the body is read by json.loads(bytes), which also
reads a UTF-8 byte order mark and UTF-16 and UTF-32; the method is the exact key "method". REST at the root:
/tasks/{id}:subscribe on GET, HEAD and POST, {id} = [^/]+. grpc.aio looks the method up by the raw :path, exactly.
