== note on ko's "git is in a dirty state" warning ==
ko prints this warning once per binary it builds: step-3.txt lines 14 and 20,
clean-check-console.txt lines 9 and 29, and four times in scan/ko-build.txt. It
reads:

    git is in a dirty state
    Please check in your pipeline what can be changing the following files:
    ?? experiments/runs/2026-09-10-go-modules/

The single dirty path is this run directory, which the step was itself writing
while ko built. Nothing the image stamp covers was dirty: check-go-sources-clean
hashes only `agents/worker fixtures/mockllm internal go.mod go.sum` (test files
excluded) and it passed, which is why the step ran at all -- the target exits 1
when any of those paths carries an uncommitted change. ko's warning is about the
whole working tree, a wider set than the stamp, and it is informational: ko
records provenance from git and says so when the tree it read is not clean.
