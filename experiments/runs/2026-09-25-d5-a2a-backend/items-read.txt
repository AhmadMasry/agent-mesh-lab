**What this PR does / why we need it:**

Adds label-selector-based service discovery for A2A backends, matching the existing MCP selector pattern. Fixes #3504.

With a multi-agent setup, every agent currently needs its own HTTPRoute rule. This PR introduces a selector on `spec.a2a` so agents can be discovered by label, removing the manual route maintenance.

**Example:**

```yaml
spec:
  a2a:
    port: 8080
    targets:
      - name: agents
        selector:
          services:
            matchLabels:
              app: a2a-agent
```

Services with `appProtocol: agentgateway.dev/a2a` are auto-discovered and exposed at `/a2a/{targetName}/...`.

**Changes:**

- **API:** `A2ABackend` gains optional `targets` (selector/static), `Host` becomes optional (deprecated). CEL validation ensures at least one of `host`/`targets` is set.
